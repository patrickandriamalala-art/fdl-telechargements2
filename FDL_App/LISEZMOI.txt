FJKM - Programme des dimanches (FDL)
====================================

A) CREER LE PROGRAMME FDL.exe  (une seule fois, sous Windows)
   1. Python doit etre installe (la commande "py" doit fonctionner).
   2. Double-clic sur  Creer_EXE.bat  (patientez 1 a 3 minutes).
   3. Le programme est cree ici :  dist\FDL.exe  (avec l'icone FJKM).
   Ensuite FDL.exe se lance seul, sans Python ni les autres fichiers.
   Windows ou l'antivirus peut afficher un avertissement ("editeur inconnu") :
   c'est normal pour un programme qui n'est pas signe ; choisissez "Informations
   complementaires" puis "Executer quand meme".

B) SANS CREER L'EXE
   py -m pip install python-docx openpyxl segno      (une seule fois)
   Double-clic sur  Lancer_FDL.bat
   Gardez les 3 fichiers .py et le dossier "assets" ensemble.

PREMIER ESSAI
   Bouton "Ouvrir..." puis exemple_juillet-decembre_2026.json.

UTILISATION
   1. Reglages : date du 1er dimanche, date de fin, groupe du 1er passage, "tokana".
   2. Groupes et membres : ajouter/retirer des membres, indiquer les absences.
   3. "Generer le programme et la repartition".
   4. Programme : cliquer sur un dimanche pour corriger un role (la correction est gardee).
   5. Equite : verifier que tout le monde participe a peu pres autant.
   6. "Exporter Word..." : programme au meme format qu'avant.
   7. "Periode suivante" : reprend l'historique pour rester equitable.
   Pensez a "Enregistrer" (fichier .json) pour retrouver votre travail.

PAGE MOBILE POUR LES MEMBRES (lecture seule)
   1. Dans l'application : bouton "Page mobile..." -> cree FDL_Mon_Planning.html.
   2. Envoyez ce fichier aux membres (WhatsApp, Messenger, e-mail...) ou mettez-le sur un site.
   3. Le membre l'ouvre dans Chrome, choisit son groupe puis son nom (une seule fois) et voit :
      - sa prochaine participation (date, role, Fidirana, equipe) et le compte a rebours ;
      - un pop-up de rappel s'il ouvre la page la veille ou le jour de sa participation ;
      - tous les passages de son groupe, et le programme complet d'un dimanche ;
      - un bouton qui ajoute ses participations a son Calendrier avec des rappels
        (la veille a 18h et le dimanche a 6h, modifiables) : ils s'affichent dans les
        notifications du telephone meme si la page est fermee.
   4. Rien ne peut etre modifie par le membre. A chaque nouveau programme, renvoyez la nouvelle page.
   Essai : ouvrez FDL_Mon_Planning_exemple.html dans Chrome.

LANGUE ET TEXTES DE LA PAGE (francais / malagasy)
   Onglet "5. Langue et textes" : choisissez "Malagasy" pour que la page mobile et l'application Android
   s'affichent en malagasy (textes, jours, mois, notifications, rappels du calendrier).
   La traduction malagasy fournie est un BROUILLON : relisez-la et corrigez ce qui ne va pas
   (double-clic sur une ligne, colonne "Votre texte"). Un texte que vous ecrivez passe toujours avant la traduction.
   Case "Laisser les membres changer de langue" : DECOCHEE (par defaut) = tout le monde voit la langue choisie
   ici, sans bouton de langue (par exemple malagasy seulement). COCHEE = chaque membre peut changer lui-meme
   (bouton "Malagasy / Francais" en haut), son choix reste sur son telephone meme apres une mise a jour en ligne.
   Vos textes personnalises ne s'appliquent qu'a la langue choisie ici.
   La langue et les textes voyagent avec le programme ("Page mobile..." ou "Publier en ligne...") :
   inutile de modifier le fichier .html a la main (l'application Android ignore ces modifications).

MISE A JOUR EN LIGNE
   Bouton "Publier en ligne..." : les membres recoivent le nouveau programme tout seuls.
   Guide pas a pas : GUIDE_MISE_A_JOUR_EN_LIGNE.txt

TELECHARGEMENTS PAR QR CODE
   Bouton "Telechargements (QR)..." : cree une page (francais / malagasy) + un QR code + une feuille a imprimer,
   pour que les membres telechargent l'application, le programme ou d'autres fichiers.
   Guide pas a pas : GUIDE_TELECHARGEMENTS_QR.txt  (module a installer une fois : py -m pip install segno)

APPLICATION ANDROID (APK)
   Voir FDL_Android.zip et son LISEZMOI_ANDROID.txt : meme page, avec notifications natives
   et chargement du programme par fichier.

CHANGER LES COULEURS
   Dans fdl_app.py, tout en haut : NAVY (bleu des boutons et titres) et FOND (fond de la fenetre).
   Remplacez le code couleur, puis relancez Creer_EXE.bat si vous utilisez FDL.exe.
