TELECHARGEMENTS PAR QR CODE - GUIDE PAS A PAS
=============================================

BUT
  Les membres scannent un QR code avec l'appareil photo de leur telephone, une page s'ouvre
  (en francais ou en malagasy), et ils telechargent l'application Android, la page du programme
  ou d'autres fichiers (PDF...). Le QR code ne change JAMAIS : vous mettez seulement les
  fichiers a jour sur GitHub, sans rien reimprimer.

ATTENTION - CONFIDENTIALITE
  Le depot GitHub doit etre PUBLIC (GitHub Pages gratuit) : toute personne qui connait l'adresse
  peut telecharger les fichiers, donc aussi le programme et les noms des membres.

----------------------------------------------------------------------
A) UNE SEULE FOIS : creer le depot public et activer GitHub Pages
----------------------------------------------------------------------
  1. Sur github.com : "+" (en haut a droite) > "New repository".
  2. Nom : fdl-telechargements.  Choisissez "Public".  Cochez "Add a README file".  "Create repository".
  3. Dans ce depot : "Settings" > "Pages" (menu de gauche).
  4. Sous "Build and deployment" : Source = "Deploy from a branch".
     Branch = "main", dossier = "/ (root)".  Cliquez sur "Save".
  5. Attendez 1 a 2 minutes, rechargez la page : l'adresse apparait en haut, de la forme
     https://VOTRE-NOM.github.io/fdl-telechargements/

----------------------------------------------------------------------
B) DANS L'APPLICATION FDL (ordinateur) : creer la page et le QR code
----------------------------------------------------------------------
  1. Barre "Exporter" > "Telechargements (QR)...".
  2. Tapez votre nom d'utilisateur GitHub et le nom du depot (fdl-telechargements).
  3. Choisissez la langue proposee au depart (chaque membre peut ensuite changer lui-meme).
  4. "Ajouter l'APK..." : le fichier app-debug.apk telecharge depuis GitHub (il sera publie sous le nom FDL.apk).
  5. "Ajouter la page du programme..." : le fichier FDL_Mon_Planning.html (cree par "Page mobile...").
     Utile pour les iPhone et pour ceux qui n'installent pas l'application.
  6. "Ajouter un autre fichier..." pour un PDF, etc. (donnez un nom en francais et en malagasy).
  7. Choisissez le dossier a creer, puis "Creer la page et le QR code".

  Le dossier contient : index.html (la page), vos fichiers, QR_telechargements.png (le QR code)
  et Feuille_QR.docx (une feuille a imprimer avec les consignes en francais et en malagasy).

----------------------------------------------------------------------
C) DEPOSER SUR GITHUB
----------------------------------------------------------------------
  1. Dans le depot : "Add file" > "Upload files".
  2. Glissez TOUT le contenu du dossier cree (index.html, FDL.apk, FDL_Mon_Planning.html, le QR...).
     Limite du navigateur : 25 Mo par fichier (l'APK fait quelques Mo).
  3. "Commit changes".  Attendez 1 a 2 minutes.
  4. Essayez : ouvrez l'adresse sur un telephone, puis scannez le QR code a l'ecran de l'ordinateur.

----------------------------------------------------------------------
C bis) IMPORTER LE PROGRAMME DANS L'APPLICATION ANDROID
----------------------------------------------------------------------
  Pour la "Page du programme", la page de telechargement propose DEUX boutons :
    - "Ouvrir" (Sokafy) : affiche la page dans le navigateur (utile pour les iPhone) ;
    - "Telecharger" (Sintony) : enregistre le fichier FDL_Mon_Planning.html sur le telephone.
  Pour l'application Android : le membre touche "Telecharger", puis dans l'application touche
  "Charger le programme" (Ampidiro ny fandaharana) et choisit le fichier dans le dossier Telechargements.
  (Si la mise a jour en ligne est configuree, le programme se met ensuite a jour tout seul.)

----------------------------------------------------------------------
D) IMPRIMER ET AFFICHER
----------------------------------------------------------------------
  Imprimez Feuille_QR.docx et affichez-la (entree de l'eglise, tableau d'affichage...).

----------------------------------------------------------------------
E) METTRE A JOUR (nouvelle version de l'APK, nouveau programme...)
----------------------------------------------------------------------
  Refaites B puis C avec les nouveaux fichiers : les fichiers du meme nom sont remplaces.
  Le QR code et l'adresse restent identiques : RIEN a reimprimer.
  (Si un telephone montre l'ancienne version, recharger la page ou vider le cache du navigateur.)

----------------------------------------------------------------------
F) CE QU'IL FAUT DIRE AUX MEMBRES (c'est aussi ecrit sur la page)
----------------------------------------------------------------------
  - Application Android : Android demande d'autoriser l'installation d'applications inconnues
    et peut afficher un avertissement Play Protect : choisir "Installer quand meme".
  - Si le membre a deja une ancienne version de l'application : la DESINSTALLER d'abord
    (chaque construction de l'APK est signee differemment).
  - iPhone : l'application Android ne s'installe pas ; utiliser la "Page du programme".
  - Internet est necessaire au moment de scanner et de telecharger.

----------------------------------------------------------------------
G) SI CA NE MARCHE PAS
----------------------------------------------------------------------
  - Erreur 404 : attendez quelques minutes apres avoir active GitHub Pages ou depose les fichiers ;
    verifiez que le depot est PUBLIC et que index.html est bien a la racine du depot.
  - Message "module segno" dans l'application : dans PowerShell, tapez  py -m pip install segno
  - Le QR ne s'ouvre pas : verifiez le nom d'utilisateur et le nom du depot dans la fenetre
    (l'adresse affichee en bleu doit s'ouvrir dans un navigateur).
